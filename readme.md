# Warlord Helper
Вспомогательное приложение по игре WARLORD (мини-приложение ВКонтакте).

- :man: **Профиль**. Магазин, коллекции, инкрустация, друзья, доны, боты (рейды, арена, ресурсы, кузница), боссы по приглашению.
- :globe_with_meridians: **Карта**. Мустафа, обыск, походы, рейды, приключения, районы, захват.
- :skull: **Боссы**. Калькулятор, список боссов.
- :punch: **Арена**. Калькулятор, сезоны, лиги, сундуки.
- :sunglasses: **Персонаж**. Таланты, достижения, ресурсы, питомцы, аватары, фоны.
- :family: **Гильдия**. Калькулятор, улучшения, кузница, академия, набеги, рейды.
- :eyes: **Разное**. Калькулятор, новые предметы, события, лотерея, обыск друзей.

## Стек
React 19, TypeScript, VKUI 8, Vite 8. Тесты — Vitest (jsdom), линтер — oxlint, форматирование — Prettier.

## Команды
Нужен Node.js и `npm install` один раз.

| Команда | Что делает |
| --- | --- |
| `npm run dev` | сервер разработки Vite на порту 10888 |
| `npm run typecheck` | проверка типов (`tsc --noEmit`) |
| `npm test` | все тесты (`vitest run`) |
| `npm run lint` | `oxlint src` |
| `npm run format` / `npm run format:check` | форматирование Prettier / проверка без записи |
| `npm run build` | проверка типов и сборка в `build/` |
| `npm run preview` | просмотр собранного `build/` |

Внутри ВКонтакте приложение работает с профилем игрока (параметры запуска, VK Storage, игровой сервер); вне ВКонтакте профиль недоступен, открываются только справочные разделы.

## Устройство
- `src/api` — запросы к игровому серверу (очередь с приоритетами, разбор XML).
- `src/app` — оболочка приложения: навигация, окна, раскладка для ПК и телефона.
- `src/panels` — страницы разделов, `src/modals` — окна, `src/components` — общие компоненты.
- `src/profile` — сессия и профили ВК, боты, бои с боссами по приглашению (`profile/invites`).
- `src/data` — справочники (предметы, боссы, карта и т. д.), `src/store` — небольшие хранилища состояния.
- `docs/game-api.md` — все методы игры (`i: N`), форматы ответов и проверенные особенности сервера. При добавлении метода его нужно описать там. `docs/Game.js` — исходный клиент игры для справки.
- `media/` — картинки, выкладываются в бакет как есть.

## Сборка и выкладка
Выкладкой управляет `.github/workflows/deploy.yml`: при пуше в `main` он синхронизирует с бакетом Yandex Cloud папки `build/` (в бакет `build/`) и `media/`. Сборка в CI не выполняется, поэтому `build/` лежит в репозитории: перед выкладкой нужно выполнить `npm run build` и убедиться, что собранные файлы попали в изменения.

- Файлы с хэшем в имени сравниваются по размеру, `index.html` загружается всегда и последним.
- Синхронизация идёт с `--delete`: файлы, которых нет в `build/`, из бакета удаляются.
- Ключи доступа и имя бакета берутся из секретов репозитория (`YANDEX_ACCESS_KEY_ID`, `YANDEX_SECRET_ACCESS_KEY`, `YANDEX_BUCKET_NAME`).

## Старый проект
В папке `old/` лежит прежняя версия приложения (Create React App, VKUI 4): `src`, `src_copy`, `public`, прежние `package.json` и `build`, а также наброски и идеи. Она не входит в сборку и хранится как справочник: на неё удобно ссылаться, но менять её не нужно.
